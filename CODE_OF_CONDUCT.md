# Code of Conduct

Tallyhound is a place to build careful software together. Everyone who takes part - in issues, pull requests,
discussions or anywhere else the project is represented - is expected to:

- be kind and patient, and assume good intent;
- give and take criticism of ideas and code, never of people;
- welcome newcomers and questions, including basic ones;
- respect that people differ in background, experience, language and opinion;
- keep private information private, including other people's data.

Not acceptable: harassment, insults, discriminatory jokes or language, sexual attention, threats, sharing someone's
private information without permission, and persistent disruption.

## Enforcement

Report a problem privately to the maintainer through GitHub (the contact on the maintainer's profile), or through
**Security > Report a vulnerability** if you need a private channel. Reports are handled confidentially. The maintainer
may remove comments, commits or other contributions that break this code, and may warn, suspend or ban anyone who
does so, in proportion to what happened.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), which you can read for a
fuller statement of the same ideas.

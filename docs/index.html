Finance audit console

Tallyhound

AI agents and fixed rules read your payables data and propose problems. Every quote is checked against the source file before anyone sees it, a second agent tries to disprove each finding, and a person makes every decision.

Try the live demo Source on GitHub

Why you can trust what it shows

Quote checkA finding is shown only if its evidence is an exact line of your file at the stated line number. An invented quote is dropped. Anyone can try to fool it on the Guardrails tab.
SkepticA second agent challenges every finding. If its verdict contradicts its own reasoning, it is asked again, and marked Unclear for a person if it still disagrees with itself.
People decideNothing is approved, rejected, held or released by software. With sign-in on, whoever ran the analysis cannot approve its findings.
Tamper-evident trailEach audit-trail entry carries a fingerprint of itself and the one before, so a changed or deleted entry shows.

Measured, not claimed

The Scorecard grades every engine against an answer key of planted problems and planted traps, and the build fails if a rule flags a trap. The challenge generator makes fresh fictional months; hard mode rewords problems so they no longer look like the rules' checks (the rules still miss one in each month), so it shows whether the AI adds anything.

What it checks

PaymentsPaid twice, paid more than invoiced, paid before the invoice, weekend releases, and a bank statement that does not match the books.
ApprovalsSelf-approval, missing POs, POs raised after the invoice, manager approving above the director limit, split orders.
VendorsUnverified bank changes, inactive vendors paid, duplicate tax IDs, missing tax forms.
Invoices (PDF)Invoices nobody approved, totals that differ, duplicates, and bank details that differ from the vendor master.
ContractsSurcharges the contract excludes, rates above the rate card, billing after the term, silent renewals.
Payment gateEight checks per line of a proposed payment run decide HOLD or RELEASE before money leaves.

How it flows

Zip of CSVs and invoice PDFs→ Column matching→ Rules and local AI agents→ Quote check→ Skeptic→ Person reviews→ Excel, PDF memo, audit trail

The AI runs on your own machine through Ollama (or LM Studio, vLLM). The analysis makes no cloud calls (alerts go only where you set them up); the Docker setup keeps everything on one server.
